# 2026-09-23

## CS114 限值插值改为 log 频率域（GJB151C-2024 对数限值线）

用户反馈运行页注入电平图的限值线形状不对：图表 X 轴是 log 频率刻度，但限值插值是 MHz 线性，
锚点之间的曲线在 log 坐标里鼓包/凹陷，不符合 GJB151C-2024 CS114 限值曲线（log 频率轴折线）的形状。

改动（全部在 `WpfEMCTestSoftware\RunTasks\CS114RunTask.cs`）：
- 新增 `InterpLog`（log10(f) 域横轴线性插值，纵轴 dB 直接线性；非正频点脏数据剔除、范围外钳端点）
- 新增 `InterpDictionaryLog`、`InterpCoeffLog` 包装
- `GetReceiverLimit`：文件模式 LimitTable 插值、定值模式 StartLevel→EndLevel 两点插值 → 均改 `InterpLog`
- `GetSignalLimitOut`：功放最大输出表 + 信号线线损表 → 均改 log 域插值
- `BuildLimitCurve`：画限值线（文件/定值两模式）改用 `InterpLog`，与算值逐字节同源；
  AddSegment 的 log 均匀加密采样（每十倍频程 100 点）保持不变

刻意保留 MHz 线性插值（不属于限值判定）：前/反向功率线损补偿、耦合值、注入电平补偿（InterpCoeff）、
校准功率表 GetCalPowerLimitDbm + BuildPowerLimitCurve（Y 是 W 线性值，画/算仍用 Interp 保持一致）。

编译验证通过（EXIT=0，无 error）。

注意：GJB151C 限值数据本身仍来自用户配置（LimitTable 文件导入 / 定值 StartLevel/EndLevel），
本次只改插值算法；若需内置标准限值表是另一个需求。
